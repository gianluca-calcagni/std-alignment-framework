## How the test was designed

A first version failed on all three counts, and each failure was diagnosed before the test was changed:
- **Strictness** failed only on grid steps within `8·10⁻¹¹` of the limit, where the divergence is saturated in floating
  point. Such steps are now skipped, and counted.
- **The relative error of the derivative** reached `8·10⁻³` only where the variance was `10⁻⁷`, i.e. an absolute error of
  `8·10⁻¹⁰`: finite-difference noise. Both errors are now reported.
- **The limit** failed only on near-ties with `t·gap ≤ 21`, which had not converged at `t = 400`. The limit is now taken at
  `t = 60/gap`.
